# Student Record Management System (Java)

A menu-driven Java application for managing student records using Data Structures and Algorithms (DSA).

### Features
- Add and delete student records
- Search students by ID using Linear Search
- Sort students by GPA using Bubble Sort
- Undo deleted records using a custom Stack
- Display all student records
- Input validation for IDs and GPA

### Concepts Used
- Java and Object-Oriented Programming (OOP)
- Singly Linked List
- Stack (LIFO)
- Linear Search
- Bubble Sort

### How to Run
```bash
javac Main.java
java Main
```

**Note:** Records are stored in memory and are not saved after the program exits.
